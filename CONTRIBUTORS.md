## How to Contribute

If you're interested in contributing to FHIR.js, please see our [Contributing Guidelines](/docs/project-management/contributors/CONTRIBUTING.md) and [Community Contribution Guide](/docs/project-management/community/COMMUNITY_CONTRIBUTION_GUIDE.md).

## Recognition Process

Contributions are recognized through the following process:

1. **Code Contributions**: All merged pull requests result in automatic addition to this list
2. **Documentation/Issue Contributions**: Significant contributions are added by the maintainers
3. **Requesting Addition**: If you've contributed and aren't listed, please submit a PR to add yourself

## Attribution Requests

Some contributors may prefer not to be listed. If you would like to be removed from this list, please contact the maintainers.
