# FHIR.js Development Roadmap

This document outlines the development plans and roadmap for the FHIR.js library.

## Current Version (1.0.0)

- Core FHIR client functionality with enhanced features
- Comprehensive error handling system
- Advanced dependency management
- Multi-level logging system
- Enhanced adapters (Node.js, Angular, jQuery, YUI)
- Response caching and optimization

## Short-Term Goals (1.1.x)

### 1.1.0 (Planned: Q3 2025)

- Expanded test coverage (80%+ coverage target)
- Improved TypeScript definitions
- Additional examples and documentation
- Performance improvements
- Bug fixes based on community feedback

### 1.1.1 (Planned: Q4 2025)

- Security improvements based on audit findings
- Additional adapter optimizations
- Documentation improvements
- Bug fixes

## Medium-Term Goals (1.2.x - 1.3.x)

### 1.2.0 (Planned: Q1 2026)

- FHIR R5 support
- GraphQL integration
- React and Vue component wrappers
- Improved bulk data handling
- Performance optimizations for large datasets

### 1.3.0 (Planned: Q2 2026)

- SMART on FHIR authentication integration
- Advanced profile validation
- Extended search capabilities
- Server metadata-based capability detection
- Improved bundling and batching

## Long-Term Goals (2.0+)

### 2.0.0 (Planned: 2027)

- Complete rewrite in TypeScript
- Modern module structure
- Framework-agnostic core with pluggable adapters
- Real-time capabilities (WebSockets, Server-Sent Events)
- Advanced caching with IndexedDB support
- Offline-first architecture
- Support for FHIR Operations Framework

## Feature Prioritization

Features are prioritized based on:

1. Security and stability
2. Community feedback and requests
3. Alignment with FHIR standard evolution
4. Integration with modern web technologies
5. Performance improvements

## Contributing

We welcome contributions from the community! Areas where help is especially appreciated:

- Bug fixes and issue reports
- Documentation improvements
- Test coverage expansion
- Performance optimizations
- Example applications
- FHIR resource support

See CONTRIBUTING.md for guidelines on how to contribute to the project.
