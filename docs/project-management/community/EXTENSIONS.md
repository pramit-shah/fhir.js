## Registering Your Extension

To add your extension to this registry:

1. Fork the FHIR.js repository
2. Edit this file to add your extension
3. Submit a pull request

Please include the following information:

- Name of your extension
- Brief description (1-2 sentences)
- Your name or organization
- Link to the repository
- npm package name (if published)

## Extension Development Guidelines

When developing extensions for FHIR.js:

1. Follow the middleware architecture pattern
2. Document your extension thoroughly
3. Include tests for your extension
4. Use semantic versioning
5. Specify the compatible FHIR.js versions

## Maintenance Standards

To be listed in this registry, extensions should meet these standards:

1. Clear documentation
2. Responsive to bug reports
3. Compatible with the latest stable FHIR.js version
4. Follows security best practices

Extensions that become unmaintained may be marked as such or removed from the registry.
