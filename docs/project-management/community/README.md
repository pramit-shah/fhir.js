## Quick Links

### For Package Users

- **Install**: `npm install fhir-js-enhanced`
- **Update**: `npm update fhir-js-enhanced`
- **Latest Version**: [npm package page](https://www.npmjs.com/package/fhir-js-enhanced)
- **Documentation**: See the [main README.md](../../../README.md)

### For Project Contributors

- **Fork**: [GitHub repository](https://github.com/pramit-shah/fhir.js)
- **Clone**: `git clone https://github.com/pramit-shah/fhir.js.git`
- **Build**: `npm run build`
- **Test**: `npm test`
- **Check for Updates**: `./scripts/check-fhirjs-updates.sh`

   - Use the [check-fhirjs-updates.sh](../../../scripts/check-fhirjs-updates.sh) script

- **GitHub Discussions**: For general questions and community discussions

## Contributing Your Work

1. **Bug Fixes**:
   - Submit PRs directly to the main repository

2. **Feature Enhancements**:
   - Create an issue first to discuss the feature
   - Submit a PR with comprehensive tests and documentation

3. **Extensions and Plugins**:
   - Register your extension in the [Extensions Registry](./EXTENSIONS.md)
   - Follow the [extension development guidelines](./EXTENSIONS.md#extension-development-guidelines)

4. **Alternative Implementations**:
   - Document your approach in the [Extensions Registry](./EXTENSIONS.md#alternative-implementations)
   - Share lessons learned and innovations
